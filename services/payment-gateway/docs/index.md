# Payment Gateway Service

PCI-DSS compliant payment processing supporting credit cards, digital wallets, and bank transfers.

## Security
- PCI-DSS Level 1 certified
- All card data tokenized at ingestion
- HSM-backed encryption keys
- Audit logging for all transactions

## Supported Providers
- Stripe (primary)
- Adyen (EU fallback)
- PayPal (digital wallet)
